# test/docs/frontend/personas/ directory files

This directory contains persona definitions for the Firefighter Station application. Each persona represents a typical user type with their goals, pain points, workflows, and test scenarios.

- `001-super-admin.md` — Super Administrator with full system access
- `002-agency-l1-team-lead.md` — Agency L1 Team Lead who reviews and approves requests
- `003-agency-l2-approver.md` — Agency L2 Approver who provides secondary approval
- `004-vendor-l1-engineer.md` — Vendor L1 Engineer who submits break-glass requests
- `005-vendor-l2-specialist.md` — Vendor L2 Specialist who approves vendor requests
- `006-system-owner.md` — System Owner who manages owned systems and delegates
- `007-team-admin.md` — Team Administrator who manages team membership
- `008-auditor.md` — Auditor with read-only access to all logs
- `009-integration-specialist.md` — Integration Specialist who configures system integrations
- `010-new-user.md` — New User pending approval
